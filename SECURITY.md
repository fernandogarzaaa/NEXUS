# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report vulnerabilities privately by email to **fernandogarzaaa@gmail.com**. Include a description of the issue, steps to reproduce, and the affected version or commit if you know it.

You can expect an acknowledgement within a few days. Please give a reasonable window to investigate and release a fix before any public disclosure.

## Supported versions

Only the latest release / the default branch receives security fixes.
